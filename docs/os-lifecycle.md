# Целевая ОС и жизненный цикл платформы

## Решение о платформе

ТЗ (разд. 2.6, 12) требовало Debian 11 и PostgreSQL. К дате выпуска первой версии стандартная
поддержка Debian 11 (в т.ч. LTS — до 31.08.2026), PostgreSQL 13 и Python 3.9 завершилась, а часть
исправлений безопасности библиотек на Python 3.9 была недоступна. **По решению заказчика от
13.10.2026 целевая ОС — Debian 13 «trixie»**; требование PostgreSQL сохранено (версия 17 из
репозитория Debian 13).

| Компонент | Версия в Debian 13 | Поддержка |
|---|---|---|
| Debian 13 «trixie» (выпуск 09.08.2025) | 13.x | безопасность от команды Debian — ориентировочно до августа 2028; LTS — до 30.06.2030 |
| PostgreSQL | 17 | сообщество — до ноября 2029 |
| Python | 3.13 | до октября 2029 |
| ansible-core (управляющий узел) | 2.21.x из venv комплекта | обновляется через `fpv-delivery-packages` |

На дату перехода все зависимости backend и Ansible-окружения проходят `pip-audit` без находок
(см. `security-review.md`).

## Что изменилось при переходе с Debian 11

| Область | Было (Debian 11) | Стало (Debian 13) |
|---|---|---|
| Python / зависимости | 3.9, FastAPI 0.128, Starlette 0.49 (известные уязвимости без исправлений) | 3.13, FastAPI 0.143, Starlette 1.7, anyio 4.15, pydantic 2.14 |
| PostgreSQL | 13 | 17; кластер создаётся с локалью `C.UTF-8` (не требует генерации локалей) |
| Ansible | ansible-core 2.15 (снят с поддержки) | ansible-core 2.21.5, коллекции ansible.posix 2.2.2, community.postgresql 4.2.0 |
| Источники apt | `/etc/apt/sources.list` | `/etc/apt/sources.list.d/debian.sources` (deb822, `Signed-By`) |
| nginx | `listen 443 ssl http2` | `listen 443 ssl` + `http2 on` (nginx 1.26) |
| Модуль pip | — | на узлах приложений ставится `python3-packaging` (требование ansible-core ≥ 2.19) |
| Пакеты | — | удалён переходный `apt-transport-https`; версии в `fpv-delivery-packages/debian/trixie/packages.manifest` |
| Пакетный репозиторий | v2026.10.0 | v2026.10.1 |

Миграции схемы БД не менялись: SQL совместим с PostgreSQL 13–17 (тесты выполнены на 13, 16 и 17).

## Перенос существующей установки (если система уже развёрнута на Debian 11)

1. Резервная копия: `fpv-pg-backup` (с проверкой восстановления) и снимок тома видеоподтверждений.
2. Новые узлы Debian 13: `install.sh --mode central … --playbook site` с пакетами `v2026.10.1`.
3. Данные: `pg_restore` копии из PostgreSQL 13 в PostgreSQL 17 (или `pg_upgrade` на копии),
   затем `python -m fpv.cli verify-audit` и `verify-videos`.
4. Перенос тома видео и сетевых папок средствами СХД с сохранением ACL (`rsync -aAX`).
5. Переключение DNS/балансировщика; старые узлы — только чтение до окончания окна отката.

## Плановое обновление

* ежемесячно: `pip-audit`/`npm audit`, пересборка `fpv-delivery-packages` с новым тегом;
* при выпуске точечных версий Debian 13 — обновление манифеста и `scripts/check-debian13.sh`;
* к 2028 г. — оценка перехода на Debian 14 по той же схеме (тесты, контейнерная установка, перенос данных).
