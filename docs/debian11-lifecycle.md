# Debian 11: эксплуатационные риски и план обновления

## Статус поддержки на дату выпуска (12.10.2026)

| Компонент (обязателен по ТЗ или следует из него) | Окончание поддержки | Статус |
|---|---|---|
| Debian 11 «bullseye», безопасность от команды Debian | 14.08.2024 | **завершена** |
| Debian 11 LTS (Debian LTS Team) | 31.08.2026 | **завершена** |
| Debian 11 ELTS (коммерческая, Freexian) | по договору, ориентировочно до 2031 г. | доступна за плату |
| PostgreSQL 13 (пакет Debian 11) | 13.11.2025 (последний выпуск сообщества) | **завершена** |
| Python 3.9 (системный в Debian 11) | октябрь 2025 | **завершена** |
| ansible-core 2.15 (последняя ветка для Python 3.9 на управляющем узле) | ноябрь 2024 | **завершена** |

Следствие: система, вводимая в эксплуатацию сейчас на Debian 11, **не будет получать
бесплатных исправлений безопасности** ОС, СУБД и интерпретатора. Часть уже известных
уязвимостей библиотек нельзя закрыть на Python 3.9 (новые версии требуют Python ≥ 3.10) —
перечень и оценка применимости в `security-review.md`.

## Риски

1. Неисправленные уязвимости ядра, OpenSSL, Samba, SSSD, nginx, PostgreSQL.
2. Невозможность обновить зависимости приложения (FastAPI, Starlette, anyio) до исправленных версий.
3. Несоответствие требованиям регуляторов и внутренним политикам ИБ по поддерживаемому ПО.
4. Сокращение совместимости с новыми версиями AD/Samba AD DC и клиентов.

## Временные компенсирующие меры (если ввод на Debian 11 обязателен)

* Договор ELTS (Freexian) для Debian 11 или аналогичная коммерческая поддержка; PostgreSQL —
  репозиторий PGDG (`apt.postgresql.org`) не продлевает поддержку 13-й версии, нужен переход на 15+.
* Изоляция: узлы ЦОД без прямого доступа в интернет, только внутреннее зеркало; периметр — nginx
  с отбрасыванием неизвестных `Host` (`default_server`), лимитами и TLS.
* Централизованный сбор журналов, мониторинг целостности (audit chain, video integrity), регулярные
  проверки восстановления резервных копий.
* Ограниченный срок: решение об эксплуатации на Debian 11 — не дольше, чем до завершения плана ниже.

## План обновления

Приложение уже проверено на новых версиях: полный набор backend-тестов (107) проходит на
Python 3.13 и на PostgreSQL 13 и 16; код не использует возможностей, отсутствующих в новых версиях.

| Этап | Содержание | Критерий завершения |
|---|---|---|
| 0. Согласование | замена обязательной платформы — по согласованию с заказчиком (ТЗ, разд. 12) | решение о целевой ОС |
| 1. Целевая платформа | **Debian 13 «trixie»** (поддержка до ~2028, LTS до ~2030): Python 3.13, PostgreSQL 17; альтернатива — Debian 12 (Python 3.11, PostgreSQL 15) | стенд на целевой ОС |
| 2. Зависимости | снять ограничения Python 3.9: FastAPI/Starlette/anyio последних версий, ansible-core 2.17+; новый тег `fpv-delivery-packages` | `pip-audit` без находок |
| 3. Ansible | `fpv_base_allowed_releases: ["11", "13"]`, версии пакетов в манифесте, `fpv_postgresql_version: 17` | `tests/ansible` + контейнерный тест на `debian:13` |
| 4. Данные | перенос БД: `pg_dump`/`pg_restore` или `pg_upgrade` 13→17 на копии, сверка `verify-audit` и `verify-videos` | восстановленная копия прошла проверки |
| 5. Переключение | поэтапно: файловые серверы и рабочие станции → БД → серверы приложений (`serial`), с окном отката | эксплуатация без Debian 11 |
