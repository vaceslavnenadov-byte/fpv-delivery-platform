# Монитор полёта

Отдельное окно для работы с выполняемым заданием: видео с камеры дрона с наложенной
телеметрией, карта маршрута с позицией дрона, переписка оператора с координатором.

## Кто и когда открывает

Кнопка **«🛰 Открыть монитор полёта»** появляется в карточке заказа, как только оператор
принял задание (статусы «Принят оператором», «Ожидает проверки готовности», «Готов к выполнению»,
«Выполняется», «Ожидает подтверждения доставки»), а также в разделе оператора «Мои задания».

| Роль | Доступ |
|---|---|
| Оператор | назначенный заказ: видео, телеметрия, переписка |
| Координатор | назначенный заказ: видео, телеметрия, переписка |
| Администратор | любой заказ |
| Заказчик, техник | нет (кнопка не показывается; телеметрия и переписка закрыты на сервере) |

Окно открывается отдельно от основного (по одному на заказ; повторное нажатие переводит на него
фокус) и не содержит бокового меню. Адрес — `/orders/<id>/monitor`. Кнопка «⛶» — полноэкранный
режим, «☰» — карточка заказа в основном окне.

## Подготовка задания в мониторе

Пока задание не начато (статусы «Принят оператором», «Ожидает проверки готовности», «Готов к
выполнению»), на месте видео у назначенного оператора — панель задания:

1. **«Проверить готовность»** — та же проверка, что в карточке заказа (регистрация и допуск дрона,
   свежая диагностика, грузоподъёмность и дальность, связь с сервисным модулем, заряд батареи).
   Если проверка не пройдена, причины показываются списком.
2. **«▶ Начать задание»** — появляется после успешной проверки. После начала панель сменяется
   видеотрансляцией с наложенной телеметрией.

Кнопки остаются и в карточке заказа; сервер одинаково проверяет права и допустимость перехода
(с `expected_version` и ключом идемпотентности). Координатор и администратор панель не видят.
До начала задания строка «Связь» показывает состояние связи самого дрона.

## Что показывается

| Область | Содержимое |
|---|---|
| Верхняя строка | дрон и заказ, фаза полёта и режим, спутники GNSS, заряд и напряжение, качество связи |
| Видео | прямая трансляция («Видео» или «Кадры»), запускается автоматически при выполнении задания |
| Наложение на видео | высота над землёй и над уровнем моря, скорость, ветер, лента курса, координаты, шкала высоты (до 1,25 предельной высоты маршрута), вертикальная скорость, перекрестие, авиагоризонт с компасом, режим, заряд, время полёта, разрешение видео, возраст данных |
| Предупреждения | нет телеметрии дольше 5 с, заряд ниже 30 %, нет спутникового решения |
| Карта | маршрут на карте-подложке, трек и дрон стрелкой по курсу, пройденные контрольные точки; «Точка N / M», расстояние до точки Б по оставшемуся маршруту, высота, время в полёте, расчётное время прибытия |
| Переписка | сообщения оператора и координатора, замечания и инциденты координатора; кнопка 📷 отправляет текущий кадр с камеры |
| Нижняя панель | режим полёта (индикатор), предельная высота, скорость, согласование маршрута, груз и его состояние, дрон и связь |

Данные обновляются по сигналам реального времени (WebSocket) и резервным опросом раз в 3 с.

## Управление полётом не выполняется

По ТЗ контур телеметрии отделён от управления: платформа не передаёт дрону команд. Плитки
«Ручной / Авто / Возврат» — **индикаторы** текущего режима по данным телеметрии
(`extra.flight_mode`, фаза `return`), а не кнопки. Управление выполняется штатным пультом
дрона. Интерфейс адаптера по-прежнему не содержит команд полёта
(`test_adapter_interface_has_no_flight_commands`).

## Данные телеметрии

Обязательные поля записи телеметрии не изменились. Дополнительные показатели сервисный модуль
передаёт в `extra` (не более 32 скалярных полей); в интерфейс выдаются только известные:

| Поле | Смысл |
|---|---|
| `satellites` | число спутников GNSS |
| `voltage_v` | напряжение батареи, В |
| `alt_msl_m` | высота над уровнем моря, м |
| `vspeed_mps` | вертикальная скорость, м/с |
| `wind_mps`, `wind_dir_deg` | ветер: скорость и направление, откуда дует |
| `pitch_deg`, `roll_deg` | тангаж и крен |
| `flight_mode` | `manual` / `auto` |
| `waypoint_index`, `waypoint_total` | текущая контрольная точка и их число (с точкой Б) |
| `video_resolution`, `video_fps` | параметры видео |

Симулятор передаёт все эти поля и летит по контрольным точкам маршрута с курсом на следующую точку.
Для реального оборудования поля заполняет адаптер (`drone-agent/fpv_agent/adapters`); отсутствующие
показываются прочерком.

## Переписка

* `POST /api/v1/orders/{id}/chat` — `{"body": "...", "attach_frame": false}`; разрешение `order.chat`
  (оператор, координатор, администратор), только назначенным на заказ (администратору — любой).
* `attach_frame: true` прикладывает текущий кадр трансляции (только при выполнении заказа); кадр
  сохраняется в объектном хранилище (`chat/<заказ>/<сообщение>.jpg`) с контрольной суммой.
* `GET /api/v1/orders/{id}/notes` — лента (сообщения, замечания, инциденты); заказчику недоступна.
* `GET /api/v1/orders/{id}/notes/{note_id}/attachment` — кадр.
* Получатель получает уведомление; каждое сообщение записывается в журнал аудита (`order.chat.message`).

Тесты: `tests/backend/test_flight_monitor.py`.
